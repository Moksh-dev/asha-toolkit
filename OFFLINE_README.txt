PROJECT A.S.H.A. — SCHOOL & VOLUNTEER AWARENESS TOOLKITS

1. Extract the ZIP into a folder on the presentation device.
2. Open offline-toolkit.html in a current Edge, Chrome, Firefox or Safari browser.
3. Choose School or Volunteer, read the overview and presenter guide, then begin.
4. Use the arrow keys for scenes, F for fullscreen and R to replay a scene visual.
5. Presenter guides can be downloaded as text or printed from either overview.

All 40 scenes, illustrations, styling and interactive activities are in this one
HTML file. No account, server, installation or internet connection is required.
Official reference links require internet. Fullscreen availability varies by browser.

The app uses installed system fonts, with the exact A.S.H.A. fallback stacks.
Optional group tallies contain only aggregate counts. They stay in the browser
tab's session storage unless exported. Private browsing or file URLs may restrict
persistence; the toolkit still works in memory. No identifying data is collected.

BEFORE EXTERNAL USE
Project A.S.H.A. leadership and the host safeguarding personnel must review the
content, audience suitability, local procedures and verified support information.
This is educational material, not a safeguarding record system or legal advice.
Never invite public disclosures, promise absolute confidentiality or investigate.

LOCAL WEB BUILD
The dist folder can also be served by a static server with SPA navigation fallback.
Serve it at the origin root. Use HTTPS outside localhost for the service worker.
Open Resources and wait for 'Offline ready' before disconnecting.
